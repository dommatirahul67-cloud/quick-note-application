# 📝 Quick Note Application

A responsive, full-stack note-taking application that helps users capture, organize, search, and manage their thoughts through a clean and customizable interface.

## ✨ Features

- **Create notes** — Add notes with a title and content.
- **View notes** — Retrieve saved notes from the database.
- **Delete notes** — Remove notes you no longer need.
- **Search notes** — Find notes by title or content.
- **Sort notes** — Sort by newest, oldest, alphabetical order, or reverse alphabetical order.
- **Pin notes** — Keep important notes easy to find.
- **Personalization** — Choose light or dark mode, accent colors, fonts, and languages.
- **Character counters** — Track title and content length.
- **Responsive design** — Use the application on different screen sizes.
- **Persistent storage** — Store notes in Supabase PostgreSQL.

## 🚀 Getting Started

### Prerequisites

- Node.js and npm
- A Supabase account and project
- Git

### 1. Clone the repository

```bash
git clone https://github.com/dommatirahul67-cloud/quick-note-application.git
cd quick-note-application
```

### 2. Install backend dependencies

```bash
cd backend
npm install
```

### 3. Configure environment variables

Create a `.env` file inside the `backend` directory:

```env
SUPABASE_URL=your_supabase_project_url
SUPABASE_SERVICE_ROLE_KEY=your_supabase_service_role_key
PORT=5000
FRONTEND_URL=http://localhost:5173
```

Replace the example values with your own Supabase project details. Never commit your `.env` file or expose your service-role key.

### 4. Configure the database

In the Supabase SQL Editor, create the `public.notes` table:

```sql
CREATE TABLE public.notes (
  id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  title text NOT NULL,
  content text NOT NULL,
  created_at timestamptz NOT NULL DEFAULT now(),
  updated_at timestamptz NOT NULL DEFAULT now()
);
```

### 5. Start the backend

From the `backend` directory, run:

```bash
node index.js
```

The backend should run at:

`http://localhost:5000`

Health check:

`http://localhost:5000/api/health`

### 6. Start the frontend

Open a separate terminal, navigate to the `frontend` directory, and run:

```bash
npx serve .
```

Open the local URL printed by the command in your browser.

The frontend's API URL must point to the running backend at `http://localhost:5000/api` for local testing.

## 🔌 API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/health` | Check backend status |
| GET | `/api/notes` | Retrieve all notes |
| POST | `/api/notes` | Create a note |
| DELETE | `/api/notes/:id` | Delete a note by ID |

### Example: Create a note

**Request**

```http
POST /api/notes
Content-Type: application/json
```

```json
{
  "title": "My First Note",
  "content": "This is my first quick note."
}
```

- Configure production CORS and environment variables appropriately before deployment.
